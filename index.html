LEO: Latent Episodic Overview for Action Chunking Transformers

Ammaar Firozi, Jake D. Browning, Bo-Hung Chen, Yu-Lun Chou, Aaron Jacobs, Linh-Co Bui
Robotics Institute, Carnegie Mellon University
Paper (coming soon) Code (coming soon) RMBench

With a memory of the episode, ACT completes Rearrange Blocks from the same start where ACT without memory fails.

Abstract

Action Chunking with Transformers (ACT) has become a strong and lightweight baseline for imitation-based robotic manipulation, but the policy conditions only on the current observation and has no mechanism for retaining information from earlier in an episode. This limits its performance on tasks where the correct action depends on events that are no longer visible, such as remembering which object was moved, which steps have been completed, or what a previous state looked like. Current policies often use Vision-Language Models to provide an overview of the history through selected frames and text descriptions, which is compute heavy at inference time and loses information by compressing spatio-temporal features into natural language.

We augment ACT with explicit memory mechanisms, a gated memory architecture and a pretrained recurrent network, and evaluate them against ACT on RMBench, a benchmark of bimanual memory-dependent manipulation tasks in the SAPIEN simulator. Reading from a memory of past frames at every step raises the success rate of ACT from 0% to 100% on Rearrange Blocks and from 32% to 68% on Put Back Block. Gating the same memory lowers both, and a memory that holds only the arm's past joint positions performs at least as well as one that also holds images.

Method

Gated memory. Following Gated Memory Policy (GMP), the first frame and every fourth past frame are stored as one token each. A cross-attention layer added to ACT's decoder reads from this cache, and a gate predicted from the current observation decides at each step whether the memory is used. With the gate closed the model is the original ACT. We also evaluate the memory with the gate always open, with only the first frame, and with the image features removed so that only past joint positions and time remain.

ACT-SMT. A fixed-size memory zt summarizes the episode. Following Supervised Memory Training (SMT), a bidirectional Transformer encoder that sees the full history produces the memory, a causal decoder predicts future observations from it, and a small recurrent updater is trained with one-step supervision to map the current memory and the next observation to the next memory. The updater is then frozen and run online, and its memory is given to ACT as extra tokens.

ACT-SMT. The encoder and decoder are used only during pretraining. The frozen updater runs at test time.

All models are trained with the ACT recipe from RMBench (6,000 epochs at batch size 8, 50 demonstrations per task with 10 held out) and evaluated with temporal aggregation.

Reading the memory at every step takes ACT from 0 to 100 on Rearrange Blocks and from 32 to 68 on Put Back Block. Adding the learned gate lowers these to 9 and 20. The arm-history memory, which keeps past joint positions and time but no images, reaches 100 on both tasks, so the gain so far comes from the arm's own history. On Put Back Block, ACT without memory returns the block to the back mat in every rollout and succeeds only when the block started there. No model solves Observe and Pick Up.

Results vary across training seeds. ACT from the RMBench code scores 38, 0 and 0 on Rearrange Blocks and 0, 49 and 0 on Put Back Block for seeds 0, 1 and 2. Runs of the memory variants on seeds 1 and 2 are in progress.
